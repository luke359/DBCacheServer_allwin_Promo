## 現況查證

- Promotion 位於 DBCache Repository 的 `Promotion` 子目錄。
- 現有 Host 為 `DBCacheServer\DBCacheServer.csproj`，目標 `net6.0`；`MysqlAcess` 位於該可執行專案的 `DBCacheServer\MysqlAcess.cs`，命名空間為 `DBCacheServer`，不是獨立函式庫。
- `MysqlAcess` 已有 `ExecuteInTransaction<T>` 與 `ExecuteInReadCommitted<T>`，但 PCS-03 的 V2 型別化查詢與交易 Context 尚未具備。
- 目前獨立 `Promotion.Data.MySql` 若直接參考 DBCacheServer，而 DBCacheServer 又參考 Adapter，會形成循環相依。因此 P4 前須由 Tech Lead 決定：將 `MysqlAcess` 抽為共用函式庫，或讓 Adapter 依賴 Core／Data 定義的抽象並由 Host 包裝現有元件。不得直接建立循環參考或反轉 PCS-07 第 7 節方向。
